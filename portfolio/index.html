How it's built

This playable ships as a single inlined HTML bundle — no runtime network requests, no image assets, no external fonts. Every visual is drawn procedurally with Pixi.js Graphics, and the build pipeline uses Vite plus vite-plugin-singlefile to collapse JS, CSS, and markup into one deployable file.

Gameplay is orchestrated by a director state machine with rigged gate pacing and a 4-second idle-assist fail-safe so the ad always completes. MRAID hooks gate startup on viewability, pause/resume the ticker when the ad hides, and route CTA clicks through mraid.open() when hosted.
